# Document Buffet V1

Static GitHub Pages version of the Mile Zero Tours document builder.

## Use

Open `index.html` locally, or publish this repository with GitHub Pages from the root folder. The default Pages URL will load the builder directly.

## Included

- `index.html` - GitHub Pages entry point
- `document-buffet.html` - same builder file, kept as an explicit named copy
- `pages/cover.html` - standalone cover template
- `assets/mzt/` - required logo, font, and image assets
- `.nojekyll` - keeps GitHub Pages from processing the static files
